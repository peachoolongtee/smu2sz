Tier 1the agent acts inside the mandate. Runs if every gate passes
  • a pure early-pay discount on a named invoice of any face, below break-even, with a coverage check (no Tier-1 ceiling on the face)
  • counter-offers and rejections within the mandate
  • draws and invoice financing on a committed, owner-approved facility, at or below the rate threshold (15% a year)
  • repayments; requests for owner approval (they only queue)
  • receipts from the bank feed or the owner
Tier 2the owner decides. Queued, then decided only with the owner token
  • rebates; changes to terms, price, volume or operations
  • any commitment whose net new future concessions exceed ¥100,000 (an early-pay discount counts ¥0); any acceptance that changes terms
  • a draw or invoice financing on a facility that is not committed and owner-approved
  • a draw the agent requests above the rate threshold (queued with its cost)
  • a receipt reported by the agent
  • applying for or adding a facility (by the owner)
  • every capex purchase (owner only)
Tier 3never executed. Refused for every caller, the owner included
  • personal guarantees; pledging collateral; issuing equity
  • changing the mandate through the API
  • adding a facility by anyone but the owner
  • any unknown operation type (fail closed)
Who sets the tierThe executor computes it from the typed operation alone. A caller-supplied tier is an unknown field (HTTP 422). Facts the operation cannot carry, such as whether an acceptance changes terms, can only raise the tier.
