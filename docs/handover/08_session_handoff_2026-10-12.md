## 5. How this session delegated (the protocol the owner asked for)

The owner's standing feedback (7 Oct): **the lead architects, specifies, reviews and merges; it does not code the waves.** Every wave or ticket ran like this:

1. **Spec first.** The lead writes a spec file (files, outcomes, tests, rules, what not to touch, the report format) and keeps the financial-presentation decisions in it. The spec names the worktree and the branch.
2. **One worktree per implementer.** `git worktree add .claude/worktrees/<name> -b <branch> dev` (or from the integration branch); two agents never share a worktree. The agent is told to use absolute paths in every command (the shell's working directory resets between calls), never to `cd` into another worktree, never to start anything on port 3000 (give it its own ports, for example 3141/8141), and to run the hygiene line before each commit.
3. **Implementers at the lower tier.** `implementer` (API) and `frontend-engineer` (web) agents on `sonnet`, launched in the background with `Agent`, the spec path in the prompt, "commit as you complete tasks, plain one-line messages, no merge; the lead merges". Research runs on `opus` (`general-purpose`), read-only, writing to the scratchpad, every claim with file:line.
4. **Independent checks before any merge.** A `code-reviewer` on the diff (findings ranked, failure scenario, fix; stability-set statement), a `design-reviewer` on user-facing surfaces (against `apps/web/DESIGN.md` and the remediation's order), a `verifier` when figures are involved (reproduce by hand from fixtures with file:line). The lead reads the reports, verifies the cited lines itself (a few `sed -n` calls), and turns the findings into a fix spec for the same implementer (resume it with `SendMessage`) or a new one.
5. **The gate, run by the lead** in the background: API full suite (`SKIP_PERF_BENCH=1 uv run --project "$PWD" --directory "$PWD" pytest -p no:cacheprovider -q -o addopts=`, about 17 min), web `pnpm typecheck && pnpm lint && pnpm test:unit && pnpm build`, mock e2e in both modes, live e2e in both modes on their own ports (`E2E_TARGET=live E2E_API_PORT=8161 E2E_LIVE_PORT=3161 pnpm exec playwright test`), zero retries as the bar. 6. **Screenshots and a cold read** for user-facing changes: `apps/web/scripts/capture-remediation.mjs` against a live stack (its header has the exact commands; set `OUT` to a dated folder), then a `design-reviewer` reading eight PNGs cold with the previous scores as the reference.
