# #112 Design system wave: tokens, three card types, the segmented control, one state vocabulary, type scale, sidebar (web)
Branch `feat/design-system` from dev (after int/connected merges). Read first: ../map-econ/common-web.md, apps/web/DESIGN.md (whole), app/globals.css, components/business/kit.tsx and ui.tsx, components/home/*, components/deals/queue/*, components/receivables/*, components/customer/*, lib/use-reduced-motion.ts, tailwind config if any. This wave adds the system and applies it where the existing components already have an equivalent; it redesigns no page. Owner's banned list: no gradients, glows, particles, parallax, glassmorphism across the dashboard, count-ups on load, decorative badges, internal labels. The app's fonts and palette stay (brand #0368e9; ok / warn / bad tokens).
1. **Motion tokens** in globals.css: `--dur-instant: 80ms; --dur-fast: 140ms; --dur: 220ms; --dur-expanded: 280ms; --dur-scenario: 350ms; --dur-narrative: 500ms; --ease-ui: cubic-bezier(.2,.0,.0,1); --ease-select: a damped spring approximation`; every existing transition duration in the web maps onto one of them (grep for `duration-`, `transition`, `ms`); under `prefers-reduced-motion` only opacity transitions remain, through the one `useReducedMotion` hook; transitions interruptible (no queued animations).
2. **Three card types** as kit components with one class each: `Card` (standard: 12–14 px radius, hairline `#e6e9ef`, no shadow), `DecisionCard` (14–16 px radius, soft shadow `0 1px 2px rgba(16,24,40,.06), 0 8px 24px rgba(16,24,40,.06)`, one strong action slot), `SelectedCard` (tinted `bg-brand-50` + 1–2 px accent border or a 3 px left rule). The attention card on Home and the raised/frosted surfaces move to `DecisionCard` (the frost and the large shadow go). DESIGN.md records the three with when to use which.
3. **SegmentedTabs** (the owner's reference: a pill track with a raised selected pill, an icon + label per pill, an optional count badge): `components/ui/segmented-tabs.tsx` with `role="tablist"` / `role="tab"` / `aria-selected`, arrow-key movement, the selected pill sliding between options (`--dur-fast`, transform only), a 44 px hit height, light-theme rendering (track `#eef1f5`, selected pill white with the hairline and a 1 px shadow, text `ink`, unselected `ink-2`), an optional `badge` (a small filled circle, red only for counts that need the owner, neutral otherwise), icons from the existing icon set (no new icon library). Replace the ad-hoc pill groups that exist today (the Receivables filter, the Deals queue tabs, the Home window and scenario switches) with it, one commit each, behaviour and test ids unchanged.
4. **One state vocabulary component** `StateWord` ({state: planned | arranged | received | repaid | owed | scheduled | agreed | pending | current | due_soon | overdue | promise_missed; text from the server}) that renders the server's word with its tone and icon, used wherever those words appear (Home rail, Receivables rows and lifecycle, the Customer page, Cash). No page composes a state word itself.
5. **Type scale** as CSS variables and kit classes: home headline 30–34, major value 28–36 (tabular numerals), section 17–20, card title 15–17, body 14–15, supporting 13 (the floor for any financial qualification), metadata 11–12 (never for a figure or a qualification). Audit the five pages for 12 px financial text and lift it.
6. **Collapsible sidebar** on laptops (≤ 1366 px): collapses to icons with labels on hover/focus, a persistent toggle, state in localStorage (try/catch), restored on load; the five destinations and the Customer drill-down unaffected.
7. **DESIGN.md**: the tokens, the three cards, SegmentedTabs, StateWord, the type scale, the sidebar, the banned list; one document.
Tests: unit tests for SegmentedTabs (keyboard, aria, badge) and StateWord; e2e: the replaced pill groups keep their specs green; reduced motion asserted on one transition per token; axe on the five pages.
