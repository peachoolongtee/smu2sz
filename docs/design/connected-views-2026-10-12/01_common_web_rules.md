# Common rules for the three connected pages (Deals queue #109, Receivables #110, Customer overview #108)
Boards: the owner's canvas https://claude.ai/artifact/JNBJtChTQVtziLwbLwYw8e (private), boards DealsQueue, ReceivablesLayers, CustomerOverview at version 17: their words and order are the spec; a local copy of each board's HTML is beside this file (../mock-econ/project/*.dc.html). Read apps/web/DESIGN.md (the A1 pattern, the Deals A1 block, the Home E block), lib/types.ts, lib/dictionary.ts, lib/api.ts, components/business/kit.tsx, components/deals/*, components/home/*, lib/use-reduced-motion.ts.
- The app's own fonts and tokens (globals.css: --font-sans body, --font-display headings): no new fonts, no new colours; blue for recommendation and action, green for completed or safe, amber for caution or pending, red for a breach; no badge as decoration; no internal labels ("Executive snapshot", "Autonomous strategy", "Retained yield", "Treasury engine", "Live stress simulation" are banned; "FLOW recommends" is the only product voice); fewer nested borders (one container per decision; a left rule, not a box, for the why).
- INVARIANT 13: the browser computes no money or date words; every string from the server or the dictionary (en and zh, 您 voice); no codes, ids or day numbers in Business mode; supporting text 13 px minimum.
- One page, one job: Deals decides; Receivables collects; Customer explains the relationship (a drill-down at /customers/[id], never a tab). Pages link, never repeat every calculation; the same figure is the same server string everywhere.
- Context in the URL and nowhere else: `customer`, `decision`, `path`, `invoice`; every customer name is a link to /customers/{id} carrying the current context; the server's `context.back {label, href}` is the back link; opening Cash from a stress deep-links with the series loaded (`/cash?stress=<buyer>:30&invoice=…`); coming back restores the selection. No new client stores.
- Motion (reduced motion: none): select a deal or an invoice: the detail replaces in place, 150–200 ms, the queue and the selected path kept; a scenario or window switch: the figures that change update together, 200–300 ms, from one server read; a lifecycle change (financing Arranged → Received → Repaid, counter Ready → Sent → Awaiting buyer): a quiet status transition, never a celebration. `aria-live="polite"` announces a selection's title once.
- Each section renders only when its field is present (optional types), the old page as the fallback, so the branch can merge before every server field lands. Mocks are never hand-edited: the lead re-records (API with FEATURE_ENVELOPE=1 FEATURE_PRICE_CURVE=1 FEATURE_COLLECTIONS_WORTH=1 FEATURE_EXPOSURE=1). Specs may carry a temporary in-spec patch of a recorded read until then, and must say so.
