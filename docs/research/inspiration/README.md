# Inspiration references (8 October 2026)

Two dashboards the owner gave as the bar for the Impeccable finish of the whole UI (wayfinder map #47, Wave 8). They are
references for density, hierarchy and finish, not a redesign brief: FLOW keeps the identity in `apps/web/DESIGN.md`.

- `2026-10-08-logistics-dashboard-light.webp`: a light logistics dashboard. KPI tiles with an uppercase eyebrow, a large
  figure, a green delta pill and a mini series; a revenue/costs line chart with soft fills, dashed gridlines and a
  tooltip card with legend bullets; an invoices table with monograms, pill filters (All / Unpaid / Paid), right-aligned
  values, a quiet kebab per row and "Show by 10" paging; a costs-by-category proportion bar with a legend; a cash
  balance bar chart against a target.
- `2026-10-08-markets-dashboard-light-dark.png`: a markets dashboard in light and dark. A top-5 table with a
  proportion bar above it; country pills as filters; KPI tiles with delta pills and "compared to previous 7 days"
  captions; a bar chart and a two-series rate line with a dated tooltip. The dark variant is not adopted.
